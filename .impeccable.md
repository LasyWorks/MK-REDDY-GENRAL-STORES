# MK Reddy General Stores Design System

## Design Context

### Users & Purpose

**Dual-User System:**
- **Customers**: Browse products, order groceries, track deliveries. Require simplicity and speed.
- **Store Admins**: Manage inventory, pricing, orders, and analytics. Require control and visibility.

The system must balance accessibility for customers with operational power for administrators. Both user types must feel their primary emotion equally supported by the interface.

**Jobs to Accomplish:**
- Customers: Quick ordering from a reliable local source
- Admins: Efficient store operations with real-time control

### Core Emotions & Brand Personality

**Primary Emotional Direction**: Trust-Driven Convenience

**Customer Sentiment**: "I can rely on this store like my local kirana, but faster."
- Trustworthy local presence
- Modern convenience layer
- Frictionless experience

**Admin Sentiment**: "I'm in complete control of my store operations."
- Complete visibility
- Efficient workflows
- Actionable insights

**Brand Personality** (3 words): **Trustworthy, Modern, Community-Driven**

*Positioning*: "A trusted local kirana, powered by modern convenience"
- Feels like: your neighborhood store
- Works like: a fast, smart app
- Helps: both customers and store owners equally

### Visual Direction

**Aesthetic**: Hybrid Clean + Slightly Vibrant
- **Base**: Minimal & clean (avoid clutter, maximize clarity)
- **Accent**: Strategic color highlights for offers, CTAs, urgency
- **Rationale**: Too minimal = boring for groceries; too vibrant = chaotic

**Design Inspiration**:
- BigBasket: Clean product listings, easy navigation
- Blinkit: Speed-focused UI, quick reorder, urgency signals
- Amazon: Trust indicators, reviews, structured information hierarchy
- JioMart: Local + digital blend, familiar cultural feel

**What to Adopt**:
- Simple, logical navigation
- Clear, prominent pricing
- Strong trust signals (reviews, verified badges, transaction clarity)
- Fast, frictionless checkout
- Regional cultural familiarity

### Color System

**Current Palette** (Tailwind):
- **Primary Accent**: Purple (#7c3aed) - modern, trustworthy
- **Retail Customer**: Green (#22c55e) - accessible, friendly
- **Wholesale/Admin**: Amber/Orange - distinct, powerful
- **Promotional**: Orange (#FF6B00) - urgency, excitement
- **Semantic**:
  - Success: Green (#15803d)
  - Warning: Amber (#b45309)
  - Error: Red (#b91c1c)
  - Neutral: Gray palette (trust, transparency)

**Strategic Color Use**:
- Purple for CTAs that build trust
- Green for retail customer experiences (approachable)
- Orange for limited-time offers (urgency without aggression)
- Grays for information-heavy admin interfaces (reduce cognitive load)

### Typography

**Current Stack**: System fonts (Tailwind defaults: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto)

**Hierarchy**:
- **H1** (Headers): font-black (900), 20-28px - commands attention
- **H2** (Sections): font-bold (700), 18-24px - clear segmentation
- **Body**: font-medium (500) to font-regular (400), 14-16px - approachable
- **Labels/UI**: font-semibold (600), 12-14px - clear affordances
- **Monospace**: For pricing, invoices, order numbers (precision, clarity)

**Key Principle**: Strong weight differentiation communicates hierarchy instantly.

### Accessibility & Performance

**Critical for Real-World Adoption:**

1. **Low-Bandwidth Optimization**
   - Lightweight UI (current: ~45kb gzipped frontend)
   - Lazy-load images, product listings
   - Progressive enhancement for slow connections (3G/4G)
   - Tier-2/3 user support is non-negotiable

2. **Lightweight & Fast**
   - Asset-light design (no heavy animations)
   - Fast First Contentful Paint (FCP < 2s)
   - Mobile-first layout (customers likely on mobile)

3. **Regional Language Support**
   - English + Telugu equally supported
   - Clear typography for both scripts
   - No visual degradation in translation

4. **WCAG AA Compliance** (Minimum Requirement)
   - Contrast ratios >= 4.5:1 for body text
   - Color not sole information carrier
   - Semantic HTML for screen readers
   - Touch targets >= 44x44px (mobile)

5. **Future-Ready**
   - Voice search interface (accessibility + convenience)
   - Elder-friendly mode (larger text, simplified flows)

### Design Principles

1. **Trust Through Clarity**
   - Clear pricing (no hidden fees, transparent GST 0%)
   - Visible payment status (picked_up = paid)
   - Reviews, verified badges, transaction history
   - Consistent, predictable patterns

2. **Convenience Without Complexity**
   - Minimize clicks to purchase (fast checkout)
   - Quick reorder for returning customers
   - Smart defaults (0% GST, auto-filled delivery address)
   - One-tap actions where possible

3. **Control for Admins, Simplicity for Customers**
   - Admin: Comprehensive dashboards, analytics, bulk operations
   - Customer: Distraction-free browsing, clear CTAs
   - Different interfaces for different mental models

4. **Local + Digital Balance**
   - Use cultural cues (community-driven language, Telugu support)
   - Modern digital interactions (fast, responsive, smart)
   - Respect regional preferences (pricing in rupees, local festivals)

5. **Performance Enables Trust**
   - Fast load times = reliability signal
   - Smooth interactions = quality perception
   - Lightweight = accessible to all users
   - Speed is a feature, not an optimization

### Component Standards

**Customer Interface**:
- Clean product cards (image, title, price, quick-add)
- Minimal form fields (phone-based login, OTP)
- One-column layouts on mobile
- Clear CTAs in accent colors

**Admin Interface**:
- Data-dense tables (but scannable with clear headers)
- Action buttons grouped by urgency
- Analytics charts with contextual insights
- Bulk operations for efficiency

**Shared Elements**:
- Consistent spacing scale (Tailwind: 4/8/12/16/24/32...)
- Monospace for any numeric data (prices, order IDs, quantities)
- Semantic color coding (no custom color associations)
- Print-friendly layouts (invoices must be accurate)
