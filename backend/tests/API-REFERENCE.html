1.1 Authentication

All protected endpoints require a JWT Bearer token in the request header:

Authorization: Bearer <access_token>

Tokens are obtained via the OTP login flow (customers) or password + OTP 2FA flow (admins).

1.2 Access Levels

LevelBadgeDescription
PublicPublicNo authentication required
CustomerCustomerAuthenticated retail or wholesale customer
AdminAdminAdmin role required

1.3 Response Format

{
  "success": true,
  "status": "success",
  "message": "Description",
  "data": { ... },
  "timestamp": "2026-02-21T15:00:00.000Z"
}

1.4 Multilingual Support

Send the Accept-Language header to get Telugu translations. Supported values: en (default), te.
