🔗 Data Relationships

Users → Orders
One user can have multiple orders. When an order is created, it stores the user_id and customer details.
Categories → Products
Each product belongs to exactly one category. Categories support multi-language names (English, Telugu, Hindi).
Products → Cart Items → Carts
A product can be added to multiple carts. Each cart belongs to one user. Cart items store product id, quantity, and price at time of addition.
Orders → Order Items → Products
When checkout happens, cart items are converted to order items. Order items store snapshot of product info (name, price, GST) to maintain historical accuracy.
Orders → Invoices
One order generates one invoice. Invoice stores billing details including customer info from order and GST breakdown (CGST/SGST).

📊 Order Processing Flow

1️⃣ User Registration → Data stored in Users table with role_id
2️⃣ Browse Categories & Products → Retrieved from Categories and Products tables with translations
3️⃣ Add to Cart → Creates/Updates cart and adds items to cart_items table
4️⃣ Checkout → Transaction: Create order, convert cart items to order items, deduct stock, clear cart
5️⃣ Generate Invoice → Creates invoice record with order and customer details, GST calculation (CGST+SGST)
6️⃣ Order Fulfillment → Order status updates (pending → processing → shipped → delivered)

✨ Key Features

🌍 Multi-Language Support: Categories and Products have translation tables supporting English (en), Telugu (te), and Hindi (hi). System fetches translations based on user language preference.
💰 GST Handling: Products store GST percentage. At cart checkout, GST is calculated per item, and at invoice level, it's split into CGST (Central) and SGST (State).
📦 Stock Management: Product stock_quantity tracks inventory. When order is placed, stock is automatically deducted. Minimum order quantity and maximum order quantity are enforced.
💳 Price Snapshots: Cart and order items store the price at the time of transaction. This preserves historical accuracy even if product prices change later.
👥 User Roles: Users are linked to roles table. Different roles (admin, customer) determine permissions and what data they can access.
